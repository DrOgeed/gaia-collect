Ethics Checklist

What this tool checks against UNESCO's AI for Environment and Ecosystems Toolkit for Policymakers, before anything gets called "AI."

  1. Is AI even the right tool here? Toolkit · Step 2, Have a Compass Before reaching for a model, the toolkit asks whether the problem actually needs one. Logging a planting and plotting a rough location doesn't — so this tool has no AI model in it at all. Arithmetic and a bounding box are enough.
  2. Data ownership stays with Gaia Collect Toolkit · Step 2, CARE Principles Every entry is written to this browser's local storage, on this device, and nowhere else. No account, no server, no third party ever holds a copy. That's a deliberate reading of data-sovereignty principles for a small, community-rooted project: the data about the land stays with the people working the land.
  3. Proportionality Toolkit · Step 3A, Responsible and Efficient AI The Plot tab is a plain scatter plot, not a mapping platform. No tiles are fetched, no geolocation is requested, no live tracking happens. The tool does only as much computation as the task needs, and no more.
  4. Locally relevant, not a fixed global list Toolkit · Step 1, Know the Foundations Species, status labels and notes are free text, not a dropdown written for someone else's ecosystem. A tool built around one region's species list silently stops fitting anywhere else; this one doesn't assume what's being planted.
  5. No greenwashing Toolkit · Step 3B, Green AI Pathways This page doesn't call itself "AI-powered" to sound credible to funders or partners. It's described plainly as what it is: a static notebook with a CSV export. Overstating the technology here would be exactly the kind of green-colonial framing the toolkit warns against.

About this tool

Gaia Field Log is a small, offline-first notebook for logging tree plantings and tracking survival over time. It was built for Gaia Collect's restoration work as part of a project for UNESCO's AI Ethics Action Cohorts, at the 4th UNESCO Global Forum on the Ethics of AI.

The Ethics Checklist tab applies UNESCO's AI for Environment and Ecosystems Toolkit for Policymakers (Constanza Gómez Mont and Carlo Angeles) to this tool's own design choices — including the choice to not use an AI model at all.

Plain HTML, CSS and JavaScript. No build step, no dependencies beyond two Google Fonts. Anyone running a small restoration project is welcome to copy and adapt it.
